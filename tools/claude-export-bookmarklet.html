📋 Claude Conversation Exporter

A bookmarklet that scrapes the current claude.ai conversation, formats it with clear ## Human / ## Assistant role markers (optimal for feeding into another AI), then lets you copy it to the clipboard or download a .txt file.

Install

Drag this button to your bookmarks bar:

Export Claude Chat

No bookmarks bar visible? Press Ctrl/Cmd+Shift+B to show it, then drag. On mobile, see the manual steps below.

Use

  1. Open any conversation on claude.ai.
  2. Scroll to the top once so the whole thread is loaded into the page (long chats lazy-load — scrolling forces older turns to render).
  3. Click the Export Claude Chat bookmark.
  4. A dialog asks: OK = copy to clipboard, Cancel = download .txt.

Source

If you'd rather paste it into a bookmark manually, copy this and paste it into the bookmark's URL/Location field. (Manual route is the way to add it on iOS/Android: create any bookmark, then edit it and replace the URL with this.)
