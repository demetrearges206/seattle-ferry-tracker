Specs

Detail color
Hard-coded #0b1a2e (basemap navy) at 32% / 100% opacity for inset deck + wheelhouse.
Bow direction
Points up at 0°. Rotate the host element by the vessel's true heading (degrees from north, clockwise).
Glow
CSS drop-shadow filter that picks up currentColor — each vessel glows in its own hull color.
Hit target
Recommend a 44×44 transparent tap area centered on the icon, even when the visual is smaller.
Anchor point
Geographic position should be placed at the icon's center (32, 32 in viewBox units), not the bow tip.

Integration

Drop the SVG into your assets and render with whatever your map layer exposes — Mapbox Marker, MapLibre HTMLMarkerElement, React Native Marker, etc. The icon does three jobs through CSS only:

/* once, in your global stylesheet */
.vessel-marker {
  display: inline-block;
  width: 36px; height: 36px;
  transform-origin: 50% 50%;
  filter:
    drop-shadow(0 0 6px color-mix(in srgb, currentColor 55%, transparent))
    drop-shadow(0 0 14px color-mix(in srgb, currentColor 28%, transparent));
}

/* per vessel — only two things change */
<div class="vessel-marker"
     style="color: #B6E84A; transform: rotate(127deg);">
  <img src="/icons/ferry-deck.svg" alt="Wenatchee" />
</div>

For React Native / native maps where currentColor isn't available on a remote asset, inline the SVG as a component and pass fill + rotation as props — the shape is small enough (3 elements) to inline cheaply.

Notes

Color contrast. All eight fleet colors above clear AAA against #0B1A2E. If you add new colors, target an APCA Lc ≥ 75 on the basemap.

Multiple vessels close together. The glow halo lets two pins overlap a little without losing identity. If three+ vessels stack, cluster them and show a count badge instead.

Heading source. If AIS heading is unavailable, fall back to course-over-ground (COG). If neither is available, render with rotation 0° and skip the glow to signal stale data.

Anchor. Place the geographic coordinate at the icon's center (32, 32), not the bow tip — rotation around the bow looks unmoored.
