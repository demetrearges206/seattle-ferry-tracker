# WSDOT API Snapshots

Fetched by .github/workflows/wsdot-snapshot.yml
Triggered by writing a keyword to request.txt

Available keywords (one per line):
  vessels    — vessellocations + vesselbasics
  schedule   — today's SEA-BI and BI-SEA schedules
  all        — everything above

Example: write 'all' to request.txt and push to main.
